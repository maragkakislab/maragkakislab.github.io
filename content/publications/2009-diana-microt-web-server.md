## Summary

The DIANA-microT web server provides access to the DIANA-microT algorithm for microRNA target prediction. The server enables researchers to identify genes regulated by specific microRNAs, query microRNAs targeting specific genes, and perform pathway-level analysis of miRNA regulatory networks.
